The solution

Reason from the evidence that survives

Everything on the map is pre-computed by this pipeline; the dashboard re-implements nothing.

Same event, one dial. The assumption moves when, never whether.

2 h
probable blackout
4 h
battery assumed alive, then dark
8 h
← mains lost at hour 0
Battery endurance is commercial-in-confidence, so it is carried as one visible assumption. Never invented per-site figures, never a countdown.
R1–R5
site rules

one site's probable state, from mains loss and elapsed time

A1–A5
aggregation rules

sites roll up to a suburb or town verdict

C1–C4
confidence rules

how fresh and consistent the evidence is

The system reports probable blackout, never certainty. No evidence is not the same as safe.
The system, live

Two events, ninety seconds

Act 1, the Feb 2024 storms: the replay turns red in fragility order as backup windows expire.    Act 2, the 3 Oct M4.8: 19 sites exposed, zero mains-loss evidence, no blackout claimed.
What it means

Built to scale, honest about limits

Statewide is four more pollers, not a new system. Same rules, same register, same map.

AT SCALE

Two audiences already served. A State Control Centre intelligence view during the event, and an AusNet planning view before it.

Accessible by design. Colour-blind-safe palette, adjustable text size, a guided tour and a plain-language glossary.

HONEST LIMITS

One distributor piloted. Eastern Victoria only, by design.

Battery endurance is assumed, not known. The assumption is always on screen.

Inference never carries the authority of observation. An educational prototype, not an operational system.

Digital infrastructure, the subject itself

Seven layers, one working system

Sensing
a 15-minute Python poller over the AusNet and VicEmergency feeds
Transport
scheduled HTTPS collection of public feeds into the project archive
Storage
timestamped snapshot archive plus a cumulative outage event register
Processing
the R1–R5, A1–A5, C1–C4 state model and the export pipeline
Interface
the dashboard: two audience views, replay, live register, analysis, accessibility
Governance
visible assumptions, honesty statements, data licensing, AI disclosure
Sustainability
polite polling of open feeds, additive scale to all five distributors
