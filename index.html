How I work

I build each project for a named person with a real question, such as a council safety officer, a police planner or an emergency intelligence officer, and design backwards from the decision they need to make.

Tools I've used

  • Honest about uncertainty. "Probable", never certain. No evidence is not the same as safe, and every assumption stays on screen.
  • Open data first. Public, licensed sources with their attribution, so anyone can check a number where it was published.
  • Accessible by design. Colour-blind-safe palettes, never colour alone, keyboard support, text size controls and guided tours.
  • Built for a named audience. Each view answers one person's question, before an event or during it.
